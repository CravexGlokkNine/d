# Omnix MCP Patch Workspace

Use this directory for human-reviewed MCP-Reborn source patches after `./gradlew setup` decompiles Minecraft 1.20.1 sources into the local `mcp-reborn` checkout.

Patches in this repository must remain limited to legitimate client UI, accessibility, rendering preference, HUD, and performance work. Do not add patches for unfair multiplayer advantages, session spoofing, packet spoofing, or anti-cheat evasion.
